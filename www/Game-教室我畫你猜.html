📖 手把手區網連線教學

1. 啟動本機伺服器

  1. 在教師電腦上執行「WEB 區網互動教學工具箱」主程式（web_exe2.py）。
  2. 程式啟動後會顯示一組區網網址，格式類似 http://192.168.x.x:埠號/。
  3. 教師電腦與所有學生裝置必須連接同一個 Wi-Fi / 區網才能互相連線。

2. 開啟遊戲並分享網址

  1. 在教師電腦瀏覽器開啟 你畫我猜 遊戲頁面（本頁面）。
  2. 點擊右上角「設定」中的【複製本頁連結】，把網址分享給學生（例如寫在黑板或用通訊軟體傳送）。
  3. 學生在自己的手機或電腦瀏覽器貼上該網址即可進入遊戲大廳。

3. 資料儲存位置

  1. 所有題庫、房間、玩家與畫布資料都會自動儲存在伺服器端的 www/data 資料夾中，關閉伺服器後資料仍會保留。
  2. 不需要註冊帳號、不需要 API 金鑰，也不會將教室資料上傳到任何雲端服務。
  3. 若要清除所有房間與題庫資料，只需刪除 www/data 資料夾中的資料庫檔案即可重新開始。
