# 🎓 WEB 區網互動教學工具箱 (Web Classroom Interactive Tool)

一個專為學校教室、研習活動與課堂教學設計的**免設定區域網路互動教學伺服器與學生作業繳交系統**。

本系統結合了 **Python PyQt5 桌面控制視窗**、**輕量多執行緒 HTTP 伺服器**與**內建本地即時資料庫**，教師端電腦只要雙擊 `啟動程式.bat` 即可自動完成環境檢查、套件安裝並開啟程式，自動取得區網 IP 並架設課堂互動網站。學生只要透過 iPad、平板、手機或電腦瀏覽器連線（或掃描 QR Code），就能即時進行搶答、投票、便利貼牆、白板協作、簡報同步、線上測驗、心智圖創作、繪圖畫布答題、語音錄音繳交、檔案上傳等互動。

---

## 🌟 核心特色

- 🚀 **雙擊即用，免安裝流程**：附贈 `啟動程式.bat` 一鍵啟動器，自動偵測／安裝 Python 與必要套件，全程免手動下指令。
- 🧩 **「剛好」系列課堂互動工具組**：內建 4 套即時互動教學模組（剛好學、剛好白板、剛好簡報、剛好測），涵蓋搶答、投票、便利貼牆、多人白板協作、PDF 簡報同步、線上測驗與成績分析。
- 🗄️ **內建本地即時資料庫（免 Firebase、免網路）**：以 `local-firebase.js` 模擬 Firestore 介面，實際資料透過教師端 Python 後端輪詢同步、寫入本機 JSON 檔案，完全區網離線可用。
- 🍡 **馬卡龍粉彩色系介面**：採用溫暖柔和的馬卡龍粉彩風格，具備圓角膠囊按鈕、磨砂玻璃質感與生動互動動畫。
- 🎙️ **iPad / 瀏覽器即時語音錄製與直接上傳**：學生可直接錄音，支援即時計時器、錄音動態紅燈、回放試聽與重新錄音，一鍵上傳至指定題號資料夾。
- 📸 **課堂教材一鍵截圖繳交**：`www/html/` 目錄下的教材網頁會被自動注入浮動「📸 截圖繳交作業」外掛，學生瀏覽教材時可隨時截圖並繳交，無需另外操作。
- 🎨 **多功能學生端畫布互動**：支援在題目背景圖上即時手繪、塗鴉、橡皮擦、多色筆刷與文字框排版，完成後一鍵自動截圖繳交。
- 📁 **智慧分題收件系統**：學生繳交作業時選擇題號與姓名，後端自動依題號（問題 1～問題 10，可自訂）建立分類資料夾。
- 🖥️ **華麗作業展示牆**：專為教室大螢幕/電子白板設計的作業展示介面，方便課堂成果觀摩與互動講評。
- 📱 **QR Code 快速連線**：教師端一鍵彈出大尺寸 QR Code，學生掃描即可連線，亦可複製網址或另存 QR 圖檔。
- 🔒 **教師管理防護機制**：首頁左下角內建教師管理入口，輸入管理密碼即可解鎖管理工具（教師多檔上傳、背景圖設定、選單設定等）。
- 💡 **多元教學輔助工具**：內建心智圖生成工具、課堂常用網址導引分享、英檢 1200 字單字卡等。

## 🚀 快速啟動（推薦）：使用 `啟動程式.bat`

**教師端只要對 `啟動程式.bat` 點兩下滑鼠，就完成所有環境設定並開啟程式**，完全不需要自己開命令提示字元、也不需要先安裝 Python。

### `啟動程式.bat` 會自動幫你做的事

1. **切換到程式所在資料夾**：確保無論從哪裡點擊捷徑，都能正確找到 `web_exe2.py` 與 `www/` 資料夾。
2. **偵測系統中是否有「真正可用」的 Python**：優先尋找 Windows 的 `py` 啟動器，找不到才改用 `python` 指令；並實際執行一段測試指令驗證它是不是真的能跑（而不只是「找得到檔名」）。這是為了排除 Windows 內建、完全沒裝過 Python 時也會存在的「假 `python.exe`」（App execution alias：一按下去只會跳出微軟商店，實際上什麼指令都不會執行），避免誤判成「已安裝」。
3. **排除 Microsoft Store 版 Python**：即使偵測到的是一個「真的能執行」的 Python，若確認它是從 Microsoft Store 安裝的版本，也會直接忽略——因為這個版本會被市集沙盒限制，導致 `pip` 永遠無法正常安裝套件。
4. **如果找不到任何可用的 Python**：
   - 優先偵測系統是否有 `winget`（Windows 內建的軟體安裝工具），若有則自動透過 `winget install Python.Python.3.12` 靜默安裝正規版 Python（**需要網路連線**）。
   - 若沒有 `winget`，或 `winget` 安裝失敗，會自動改用**第二種安裝方式**：直接從 python.org 下載官方安裝程式（`python-3.12.7-amd64.exe`），並以靜默模式為目前使用者安裝（`/quiet InstallAllUsers=0 PrependPath=1 Include_pip=1`），**不需要系統管理員權限**。
   - 兩種方式都失敗才會顯示錯誤，請你自行至 [python.org](https://www.python.org/downloads/) 下載安裝，並提醒務必勾選「Add python.exe to PATH」與「pip」。
   - 只要有任何一種方式安裝成功，會提示「請關閉此視窗並重新點兩下啟動器」（因為 Windows 需要開一個新的視窗才能讀到剛裝好的 Python 路徑），照做即可。
5. **檢查並修復 pip**：確認 `pip` 套件管理工具可正常運作；若異常會先嘗試 `ensurepip --upgrade` 修復，並在修復後**重新驗證**是否成功；若仍失敗，會再自動下載 `get-pip.py` 補裝一次。
6. **檢查程式所需的 4 個必要套件**（`PyQt5`、`PyQtWebEngine`、`qrcode`、`Pillow`）：
   - 若已安裝，顯示 `[OK] All required packages are already installed.` 並直接跳過安裝步驟。
   - 若缺少，自動執行 `pip install --upgrade pip` 與 `pip install PyQt5 PyQtWebEngine qrcode Pillow`（**需要網路連線**）；若因權限問題失敗，會自動改用 `pip install --user` 重試一次。
   - 若安裝仍然失敗，會顯示 pip 的實際錯誤訊息並提示可自行手動執行的安裝指令。
7. **確認 `web_exe2.py` 是否存在**：找不到會直接顯示錯誤，提醒必須將 `.bat` 與 `web_exe2.py` 放在同一個資料夾內。
8. **啟動主程式**：
   - 優先以 `pythonw.exe`（無命令列黑窗版本的 Python）背景啟動 `web_exe2.py`，讓桌面只會看到程式視窗、不會多出黑色終端機視窗。
   - 若找不到 `pythonw.exe`，則退而求其次以一般 `python`/`py` 指令啟動。
9. 啟動指令送出後，`.bat` 視窗即自動關閉，接下來的操作全部在跳出的桌面應用程式視窗中進行。

> ⚠️ 第一次執行若需要自動安裝 Python 或套件，請保持網路暢通，整個流程可能需要 1～3 分鐘，請耐心等候，不要中途關閉黑色命令視窗。之後再次啟動時，由於環境已備妥，會在幾秒內直接開啟程式。

### 操作步驟

1. 對資料夾內的 **`啟動程式.bat`** 點兩下。
2. 依照上方流程等待環境檢查／安裝完成。
3. 程式視窗開啟後，上方會顯示目前的 **連線網址**（例如：`http://192.168.1.100:8000`），代表伺服器已成功啟動。
4. 接著即可依照下方「學生連線方式」讓學生載具連上系統。

## 🛠️ 手動啟動方式（進階／開發者）

若不使用 `啟動程式.bat`，也可以自行以命令列啟動，方便除錯或自訂環境執行：

### 1. 執行環境需求
- **作業系統**：Windows 10 / 11
- **Python 版本**：Python 3.8 以上

### 2. 安裝必要套件
```bash
pip install PyQt5 PyQtWebEngine qrcode pillow
```

### 3. 執行主程式
```bash
python web_exe2.py
```

> 程式啟動時也會自動檢查上述套件是否安裝，若缺少會彈出對話框詢問是否自動安裝（等同於 `.bat` 步驟 5 的行為）。

啟動後會出現現代化桌面應用程式視窗，上方會顯示目前的 **Server URL**（例如：`http://192.168.1.100:8000`）。

> **提示**：若 8000 連接埠已被其他程式占用，可在上方 Port 欄位輸入新的埠號（例如 `8080`），並點選 **「⚡ 重啟伺服器」**。

## 📶 學生連線（支援 QR Code 掃描）

確保學生載具（iPad / 平板 / 筆電 / 手機）與教師端電腦連接在**同一個 Wi-Fi 或區域網路**下：
- **方式 A（掃描 QR Code）**：教師點選應用程式頂部的 **「📱 QR Code」** 按鈕，將跳出的大尺寸 QR Code 投影至大螢幕，學生開啟相機直接掃描即可連線進入系統！QR Code 視窗亦提供「複製網址」與「儲存圖片」按鈕。
- **方式 B（輸入網址）**：學生開啟瀏覽器手動輸入視窗上方顯示的網址。
- 若忘記網址，教師也可點選頂部 **「📋 複製」** 按鈕複製網址後貼給學生，或按 **「🌐 瀏覽器開啟」** 在系統瀏覽器中確認畫面。

## 📖 各功能模組詳細說明

### 1. 首頁與學生繳交中心 (`index.html`)
- **馬卡龍導覽按鈕**：
  - 🧩 **剛好互動工具**：下拉選單開啟「剛好學」「剛好白板」「剛好簡報」「剛好測」四大即時互動教學模組（詳見下方第 2 節）。
  - 🔗 **網址分享**：開啟課堂常用連結導引頁。
  - 🧠 **心智圖創作**：開啟節點心智圖繪製與繳交工具。
  - ✏️ **課堂繳交**：支援輸入學生姓名、選擇題號（可自訂，預設問題 1～10），並可選擇使用「即時畫布」或「選取圖片檔案」進行繳交。
  - 📁 **檔案上傳**：純淨直接的檔案上傳工具，支援點選與檔案拖曳上傳。
  - 🎙️ **語音錄音**：支援在 iPad 與瀏覽器直接錄音，具備即時秒數計時器、錄音波形燈、試聽播放器與重錄功能，一鍵上傳音訊檔案。
- **檔案瀏覽與預覽**：提供清晰卡片式檔案總管介面，點選圖片即可彈出放大預覽，音訊檔案亦有專屬圖示。

### 2. 「剛好」系列即時互動教學模組
這四套工具皆透過 `local-firebase.js` 讀寫教師端內建的本地即時資料庫（見下方「本地即時資料庫」說明），無需連外網、無需申請 Firebase 帳號即可多人即時同步。

- **🙋 剛好學 (`01classtools.html`)**：課堂互動教學模組合集，教師輸入教室代碼建立教室、學生輸入相同代碼加入課堂，內含：
  - **搶答**：教師發起搶答，學生端搶按按鈕，系統即時判定最快的學生。
  - **快速投票**：教師設定投票題目與選項（可設定匿名投票），即時顯示投票統計圖表。
  - **便利貼牆**：學生送出便利貼留言，依時間分組即時呈現在牆面上。
  - **閱讀測驗**：教師出題、學生作答，並提供橫向長條圖統計正確率。
  - **作品觀摩與投票**：學生瀏覽同學作品並按讚投票，即時統計人氣。
- **📋 剛好白板 (`02classwhiteboard.html`)**：多人即時協作數位白板。教師建立白板（可自訂或自動產生白板 ID）並可切換／新增多頁畫布，學生輸入白板 ID 即可加入同步繪圖、移動畫布、使用畫筆等工具；支援離開白板（保留資料）與刪除白板資料。
- **📊 剛好簡報 (`03classppt.html`)**：上傳 PDF 簡報自動轉檔建立互動課堂，教師端可控制翻頁並即時同步至所有學生畫面，同時可查看學生即時回饋、匯出簡報資料。
- **📝 剛好測 (`04classquiz.html`)**：線上測驗工具，支援手動或 AI 輔助出題、學生即時作答、成績即時統計分析（含成績分佈圖表），並可將成績報表匯出為 CSV 檔案。

### 3. 學生教材專注模式與教師後台解鎖
- **學生教材專注模式（預設）**：開啟網頁時，根目錄檔案總管預設**僅呈現 `html` 教材資料夾**，其他所有系統設定檔、背景圖與繳交資料夾一律隱藏，引導學生專注於當堂互動教材。
- **教材頁面自動掛載截圖繳交外掛**：只要是 `www/html/` 資料夾下的 HTML 教材，伺服器回傳時會自動在網頁中插入浮動的「📸 截圖繳交作業」按鈕，學生可隨時將目前畫面截圖後選擇題號與姓名直接上傳，不需另外切換頁面。
- **教師後台管理解鎖**：
  - 在首頁左下角點擊 ⚙️ 齒輪圖示，輸入管理者預設密碼：`tpet`。
  - **根目錄呈現**：驗證成功後，根目錄會清晰呈現**所有資料夾**（`html/`、`upload/`、`bg/` 等）以及**所有管理工具（`.html` 檔案）**，其餘非 HTML 的程式與雜檔自動過濾不呈現，且右上角會出現「⚙️ 教師管理」下拉選單（查閱作業、設定作業選單、設定分享網址、設定作業背景圖）。
  - **子目錄呈現**：點進任何子目錄時，完整呈現該目錄下的所有類型檔案（圖片、聲音、文件等），不受任何類型限制。

### 4. 教師設定背景圖工具 (`教師設定背景圖工具.html`)
- 教師在教材或簡報上截圖後，進入本頁面直接按鍵盤 `Ctrl + V` 貼上圖片。
- 選擇對應的題號，點擊「設定背景圖」，系統即會將背景圖儲存至 `www/bg/` 資料夾供學生畫布載入。

### 5. 教師多檔案上傳工具 (`教師多檔案上傳工具.html`)
- 方便教師一次選取多個範例檔案或作業素材，批次上傳到指定的題號目錄中。

### 6. 設定作業選單 / 設定分享網址
- **`設定檔案上傳選單名稱.html`**：管理「課堂繳交」下拉選單顯示的題號名稱清單，儲存後寫入 `www/questions.txt`。
- **`設定分享網址.html`**：管理「網址分享」頁面顯示的常用連結清單，儲存後寫入 `www/url.txt`。

### 7. 作業呈現介面 (`作業呈現介面V3.html`)
- 點選題號標籤，系統自動讀取 `upload/` 對應目錄下的所有學生作業。
- 提供卡片式排版、學生姓名標籤、圖片放大檢視、隨機抽籤與全螢幕投影模式，極為適合課堂公開講評。

### 8. 🎴 普普風配對遊戲生成器 (`普普風配對遊戲生成器.html`)
- **多元遊戲模式**：支援「翻卡練習」、「隨機配對」與「打地鼠」三種趣味互動模式，內建注音字體切換與語音播音支援。
- **AI 輔助出題 & 批次匯入**：內建成語、英文單字、中英翻譯、注音練習、數學算式、自然科學等 AI 提示詞範本，可一鍵複製並批次匯入題庫。
- **直接生成與伺服器儲存**：生成完成後直接透過後端 `/saveQuiz` API 儲存至 `www/html/配對遊戲/` 目錄中，並提供「立即開啟遊戲」與「下載備份檔」功能。

### 9. 📖 PIRLS 閱讀測驗產生器 (`PIRLS 閱讀測驗產生器.html`)
- **AI 智慧命題**：結合 Google Gemini API，支援「指定主題原創寫作」與「自訂文章命題」，精準產出符合 PIRLS 四大認知理解層次的 10 題選擇題。
- **手動命題與圖片文本**：支援手動貼上題庫，或上傳課文照片／文本圖片（自動壓縮轉 Base64 封裝）。
- **自動發布**：生成後自動儲存至 `www/html/閱讀測驗/` 目錄，並提供課堂即時作答與自動計分分析。

### 10. 🗺️ 互動式地圖標示測驗練習工具 (`互動式地圖標示測驗練習工具.html`)
- **地圖互動標記**：教師可自訂地圖與多個地理標記點，建立問答測驗與練習。
- **自動存檔**：測驗網頁一鍵直接發布儲存至 `www/html/地圖測驗/` 目錄。

## 🗄️ 本地即時資料庫（供「剛好」系列工具使用）

`web_exe2.py` 內建一個簡易的「本地文件資料庫」（`LocalDocDB`），模擬 Firestore 的集合／文件（collection/document）結構，讓「剛好學」「剛好白板」「剛好簡報」「剛好測」等工具可以在**沒有網路、沒有雲端帳號**的情況下，透過教師端電腦達成多人即時同步：

- 一般資料（教室狀態、搶答結果、投票、便利貼、白板內容、簡報進度等）統一儲存於 `www/data/local_db.json`。
- 「剛好測」的題庫資料則各自獨立儲存成 `www/quiz/<測驗ID>.json`，避免單一檔案過大。
- 前端頁面透過 `www/local-firebase.js` 呼叫下方「後端 API 規格」中的 `/api/db/*` 路由，以短週期輪詢方式達到接近即時（<3ms 級延遲）的資料同步效果。

> 若要清空所有課堂互動資料重新開始，可關閉程式後刪除 `www/data/local_db.json` 與 `www/quiz/` 內的檔案（部分工具如「剛好白板」也提供介面內「清空整個資料庫」的按鈕）。

## 🔧 後端 API 規格說明

`web_exe2.py` 提供之 HTTP 介面：

| 方法 | 路徑 | 說明 | 參數範例 / 格式 |
| :--- | :--- | :--- | :--- |
| `GET` | `/` | 系統首頁 | 自動導向至 `/index.html` |
| `GET` | `/api/list?path=<rel_path>` | 取得指定目錄下的檔案列表 (JSON) | `path=upload/問題1` |
| `POST` | `/upload` | 學生作業 / 檔案 / 錄音檔 / 截圖上傳 | `multipart/form-data`<br>- `name`: 檔案名稱（如 `學生姓名.m4a` 或 `學生姓名.png`）<br>- `question`: 題號子目錄<br>- `file`: 檔案二進位資料 |
| `POST` | `/setBg` | 設定畫布題目背景圖 | `multipart/form-data`<br>- `question`: 題號<br>- `file`: 背景圖檔案 |
| `POST` | `/saveUrls` | 儲存「網址分享」清單至 `www/url.txt` | JSON `{"content": "..."}` 或純文字 |
| `POST` | `/saveQuestions` | 儲存「課堂繳交」題號選單至 `www/questions.txt` | JSON `{"content": "..."}` 或純文字 |
| `POST` | `/saveQuiz` | 儲存測驗／遊戲 HTML 檔案至指定子目錄（如 `配對遊戲`、`閱讀測驗`、`地圖測驗`） | JSON `{"title": "...", "category": "配對遊戲", "html": "..."}` |
| `GET` | `/api/db/get?path=<doc或collection路徑>` | 讀取本地資料庫中的單一文件或整個集合 | `path=classrooms/ABCD` |
| `GET` | `/api/db/all` | 取得整個本地資料庫的完整內容與版本號 | — |
| `POST` | `/api/db/set` | 新增／覆寫指定路徑的文件 | JSON `{"path": "...", "data": {...}, "merge": false}` |
| `POST` | `/api/db/update` | 合併更新（僅更新指定欄位）指定路徑的文件 | JSON `{"path": "...", "data": {...}}` |
| `POST` | `/api/db/add` | 在指定集合下新增一筆帶自動產生 ID 的文件 | JSON `{"path": "collection路徑", "data": {...}}` |
| `POST` | `/api/db/delete` | 刪除指定路徑的文件（含其所有子文件） | JSON `{"path": "..."}` |
| `POST` | `/api/db/query` | 依條件查詢集合內的文件 | JSON `{"path": "...", "where": [["field", "==", "value"]]}` |
| `POST` | `/api/db/batch` | 一次執行多筆 set／update／delete 操作 | JSON `{"operations": [{"action": "set", "path": "...", "data": {...}}]}` |

## 💡 常見問題與排除 (FAQ)

**Q1：雙擊 `啟動程式.bat` 後，黑色視窗一閃就關掉了，什麼都沒發生？**
- 請重新以滑鼠雙擊開啟（不要用系統管理員權限開啟的終端機貼上路徑執行），並留意視窗中是否出現紅字 `[ERROR]` 訊息。若訊息為找不到 `web_exe2.py`，請確認 `啟動程式.bat` 與 `web_exe2.py` 是否放在同一個資料夾內、且資料夾未被移動或改名。

**Q2：`啟動程式.bat` 顯示安裝 Python 或套件失敗？**
- 請確認電腦已連上網路。若公司／學校網路有防火牆或代理伺服器限制，可能導致 `winget` 或 `pip` 安裝失敗，此時可請資訊組協助開放網路，或改由人工下載安裝 [Python](https://www.python.org/downloads/)（安裝時務必勾選「Add python.exe to PATH」）後，於命令提示字元手動執行：
  ```bash
  pip install PyQt5 PyQtWebEngine qrcode Pillow
  ```
  安裝完成後再重新雙擊 `啟動程式.bat` 即可。

**Q2-1：新電腦第一次使用，出現「pip not found」、`ensurepip` 修復失敗、下載 `get-pip.py` 也失敗？**
- 最常見的原因其實是**這台電腦根本沒有安裝過真正的 Python**：Windows 內建一個空殼版的 `python.exe`（App execution alias），沒裝過 Python 時只要輸入 `python` 也「找得到」、甚至能被判斷成「已安裝」，但實際上執行任何指令都沒有真正作用（原本設計用來一按就跳出微軟商店）。另一種常見情況則是誤裝了 **Microsoft Store 版的 Python**，雖然能正常顯示版本號，但執行環境被市集沙盒（sandbox）限制寫入權限，`pip`／`ensurepip` 永遠無法安裝套件成功。
  - `啟動程式.bat` 現在會先用實際執行指令的方式驗證偵測到的 Python 是不是「真的能用」，並自動排除上述兩種情況；確認需要安裝時，會先嘗試 `winget`，若沒有 `winget` 或安裝失敗，會自動改成**直接下載 python.org 官方安裝程式並靜默安裝**（不需要系統管理員權限）。只要看到「請關閉視窗並重新雙擊啟動器」，照做即可。
  - 若兩種自動安裝方式都失敗，才需要自行至 [python.org](https://www.python.org/downloads/) 下載官方安裝檔安裝（**不要**從 Microsoft Store 安裝），安裝時勾選「Add python.exe to PATH」與「pip」，安裝完成後重新雙擊 `啟動程式.bat`。
  - 若確認已安裝正規版 Python 但問題依舊，多半是網路／防火牆封鎖了 `bootstrap.pypa.io`、`pypi.org` 或 `python.org`，請洽資訊人員開通網路後再試。

**Q3：學生在 iPad 上錄音時出現權限提示？**
- 首次使用請點選「允許」瀏覽器取用麥克風。如未跳出，可在 iPad 的「設定」>「Safari」>「麥克風」中確認已設為允許。

**Q4：如何更改預設的教師管理密碼？**
- 請開啟 `www/file_password.js`，將第 11 行的 `if (pwd === "tpet")` 修改為您偏好的密碼即可。

**Q5：學生裝置無法連上伺服器網址？**
- 請確認教師端電腦與學生載具連上同一個 Wi-Fi 基地台（或同一個區域網路網段），並確認教師端防火牆已允許 Python（或 `啟動程式.bat` 啟動的 `pythonw.exe`）通訊。

**Q6：「剛好學／剛好白板／剛好簡報／剛好測」的資料存在哪裡？換一台電腦教學會不見嗎？**
- 所有互動資料都儲存在教師端電腦本機的 `www/data/local_db.json`（及 `www/quiz/` 內各測驗檔案），並非雲端同步，因此僅在同一台教師端電腦、同一個區域網路下有效；更換電腦或搬移 `www` 資料夾時，只要一併複製這些檔案即可保留原有資料。
